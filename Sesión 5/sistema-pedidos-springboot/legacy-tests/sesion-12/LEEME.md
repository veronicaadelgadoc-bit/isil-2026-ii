# Pruebas heredadas fuera de compilación (PA4)

Estas tres pruebas del proyecto base referencian clases que en la **Sesión 12** se
trasladaron a `pedidos-reportes-service` (`PedidoApiController`,
`PedidoReporteJdbcRepository`, `repository.projection.*`). En la rama base ya **no
compilaban** dentro de `sistema-pedidos-springboot`, lo que impedía ejecutar `mvn test`.

Se movieron aquí sin modificar su contenido para conservar la evidencia histórica.
No forman parte de las pruebas nuevas de PA4.
